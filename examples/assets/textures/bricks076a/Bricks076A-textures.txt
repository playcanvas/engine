Notes:
* Converted from the 1K PNG set to webp, which came out at 1.4MB against 5.1MB for the
  equivalent JPG set. Quality 95 for the normal and height maps, as compression artifacts
  in those show up as shading and marching errors, and quality 90 for the rest.
* The set also ships a DirectX convention normal map, which is not included here - the
  engine expects the OpenGL convention one (green pointing up), which is NormalGL.
* Higher resolutions, and the source .blend / .usdc / .mtlx files, are available from the
  page above if more of the set is ever needed.
